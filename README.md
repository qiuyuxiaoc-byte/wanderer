# 世界尽头的漫游者 · The Wanderer at the End of the World

一个可以直接在安卓手机浏览器里运行的低多边形 3D 漫游游戏。单文件、无外部依赖、离线可玩。

## 怎么打开

**方式一（最推荐，手机直接玩）**：点击聊天里的这个链接即可在 Minis 内置浏览器打开并游玩：
`minis://shared/wanderer/wanderer.html`

**方式二**：把 `wanderer.html` 复制到手机任意目录，用 Chrome / 夸克 / Edge 等浏览器打开（`file://` 也可直接运行）。

> 横屏体验最佳。进入后如果浏览器不支持锁定方向，会出现「请将手机横过来」的提示，点「仍然以竖屏游玩」也能玩。

## 操作

| 位置 | 操作 |
|---|---|
| 屏幕左侧任意处按住拖动 | 虚拟摇杆：向 上 / 前 推 = 前进，向 下 / 后 拉 = 后退，左右 = 侧移（人物会自动转身） |
| 屏幕右侧拖动 | 自由旋转视角（松手即停） |
| 左上角圆形小地图 | 点一下打开「旅途地图」，可看到整条走过的路线、四季分段、湖泊与当前位置 |
| 右上角 ♪ / ❙❙ | 静音 / 暂停 |

## 内容

- 一位低多边形旅人：草帽、外套、背包、手杖，腿臂摆动 + 身体起伏的行走动画
- 一条永不重复的山径：程序化曲线 + 起伏地形，缓弯、坡道、山谷
- 四季连续过渡：春 高山草甸 → 夏 广阔平原 → 秋 喀斯特峰林 → 冬 人间边界 → 回到春
  - 每季 220 米，交界 88 米内渐变（草地颜色、树冠颜色、山形、雾、天空、光照全部连续插值）
- 山、湖、河湾、云、雪、野花、草丛、岩石、树林
- 程序化环境音：风声 + 水声（靠近湖面变响）+ 极简和声铺底

## 技术

- Three.js r128 内联在 HTML 中，完全离线
- 地形 / 群山 / 植被分块生成并循环复用，长时间行走内存不增长（实测 2700 米，场景对象数保持不变）
- 约 87 个绘制调用、5 万三角面
- 动态分辨率：帧率低于 40 自动降低渲染倍率
- rAF 不可用的内嵌浏览器会自动切换到定时器驱动，保证动画不卡死

## 已知限制

- 内嵌 WebView 可能无法强制锁定横屏（浏览器限制），此时依赖提示界面
- 人物没有碰撞体积，可以穿过树木岩石（仅为观赏性漫游，不做阻挡）
- 远景为剪影层次，不参与实时阴影
